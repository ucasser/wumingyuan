# 无名园学术知识库

面向本地学术文献的 PDF 知识库。用户只需持续把 PDF 放进“PDF原件”目录，然后在网页点击“扫描并导入”。

## 核心流程

1. 自动检查 PDF 每一页是否存在可靠文本层。
2. 正常页面直接提取；缺少文本的页面按小批次调用飞桨 OCR。
3. 逐页检测文字层，有文字直接提取；扫描页才调用 OCR。限制内整本一次提交，超限自动拆分，每次任务完成后写入页面缓存，可停止、可续传。
4. 保存带页码锚点的 Markdown，并建立两套逻辑分块：知识块和引文块。
5. 使用本地 bge-m3 向量化，写入 LanceDB。
6. 网页提供知识问答与原文检索；结果可打开原 PDF 对应页和 Markdown。

## 数据目录

- `无名园书籍库/PDF原件`：用户放入 PDF 的唯一入口。
- `data/library/ocr/<document-id>/document.md`：按页 Markdown。
- `data/library/ocr/<document-id>/pages.json`：OCR 页面缓存。
- `data/lancedb/academic_chunks_v3.lance`：双分块索引。

PDF 原件不会被改名或移动。内部以内容哈希生成稳定文献 ID。

## 使用

双击 `start.command`，打开 `http://127.0.0.1:8888`。

- “扫描并导入”：增量处理新 PDF，已入库且内容未变化的文件自动跳过。
- 每次导入结束后自动合并向量碎片并清理历史事务版本，避免知识库长期膨胀。
- “停止”：当前飞桨请求完成后停止，已经完成的页面不会丢失。
- “知识问答”：检索知识块，由本地大模型综合回答并列出来源。
- “查找原文”：只返回引文块，不让大模型改写。

飞桨 OCR 会把需要识别的小批 PDF 页面上传到飞桨官方服务。普通文本 PDF 不会上传。
