# 学术写作风格指南（通用框架版）

> 本指南适用于中文马克思主义哲学史、马克思主义哲学中国化、思想史类论文写作与大语言模型辅助改写。
>
> 本指南以优秀中文社科论文的论证方式为参照，吸收何萍教授相关论文中“问题意识明确、思想史定位清楚、材料处理扎实、判断稳健克制”的写作特点，但不机械复刻任何一位作者的表面句式。
>
> 本指南提供通用写作框架，而不是针对某一具体研究对象的固定段落模板。所有示例均采用“研究对象”“某一概念”“某一文本”“某一思想家”等通用占位表达，使用时应替换为具体论文内容。

---

## 一、文档定位与使用原则

### 1.1 本指南解决什么问题

本指南用于解决大语言模型辅助论文写作中常见的六类问题：

1. 段落没有明确任务。
2. 首句不能直接提出判断。
3. 引文堆砌而缺少分析。
4. 句子逗号密度过大，主干不清。
5. 判断过满，容易下绝对结论。
6. 语言不符合中文马克思主义哲学史、马克思主义哲学中国化、思想史研究的表达习惯。

### 1.2 本指南不做什么

1. 不提供某一具体题目的固定段落结构。
2. 不要求机械模仿某位学者的表面句式。
3. 不鼓励套用“不是A而是B”“由此可见”“具有重要意义”等固定表达。
4. 不鼓励使用其他学科概念来包装论文语言。
5. 不允许为了语言顺畅而改写直接引文原文。

### 1.3 总写作原则

1. 每段必须有明确论证任务。
2. 每段首句必须直接提出本段核心判断。
3. 每段首句应尽量是完整判断句，除非句子特别长，否则首句中间不要使用逗号。
4. 段内可以使用“第一、第二、第三”展开，也可以不用。是否分层应由论证内容决定，不能机械套用。
5. 思想史类段落通常按照“提出观点—解释观点—引文印证—进一步分析—得出结论或评价”的顺序展开。
6. 引文要用全角“”符号引住，突出出来，用于印证、限定或推进观点，不用于展示材料储备。
7. 引文之后必须继续分析。
8. 控制逗号密度。句子可以长，但主干必须清楚。
9. 不轻易使用绝对化判断。
10. 不使用非中文马克思主义哲学史、马克思主义哲学中国化、思想史研究领域的词语。
11. 不自造概念，不把其他领域词语随意引入论文。
12. 直接引文必须使用中文双引号“”，不得使用英文双引号。
13. 正文中不得保留行内括注，注释应转化为脚注标号和脚注占位。

## 二、通用段落框架

### 2.1 思想史论述段

适用场景：说明某一概念、文本、人物、论争或思想现象在思想史中的位置。

基本顺序：

```text
提出判断
↓
解释该判断的思想史背景
↓
引入文本或材料印证
↓
分析材料所说明的问题
↓
回到本段判断
```

通用示例：

```text
某一研究对象应放在特定思想史脉络中理解。
在此之前，相关问题主要表现为……；到某一历史阶段，该问题开始呈现出新的理论形态。
某一文本指出：“……”。①
这段论述表明，研究对象在这一时期已经不只是……，而开始同……问题联系起来。
由此看，研究对象的思想史意义主要体现在它对既有问题的重新说明。
```

注意：使用时应将“某一研究对象”“某一历史阶段”“某一文本”等替换为具体内容，不得保留占位词。

### 2.2 概念界定段

适用场景：解释论文中的核心概念，说明概念的内涵、边界和使用范围。

基本顺序：

```text
提出概念定义
↓
说明概念不能泛化为什么
↓
说明概念与相关概念的区别
↓
引文印证
↓
归纳该概念在本文中的用法
```

通用示例：

```text
所谓某一概念，指的是
所谓某一概念，即
某一论者指出：“……”。①
这段论述说明，该概念的关键不在于一般意义上的……，而在于它把……与……联系起来。
因此，本文使用这一概念时，主要取其在某一历史语境中的理论含义。
```

### 2.3 文本分析段

适用场景：分析某一著作、文章、读书笔记、演讲、报告或书信材料。

基本顺序：

```text
指出文本的核心问题
↓
说明文本出现的历史条件
↓
引用文本关键表述
↓
分析文本表述的含义
↓
评价文本在思想史中的位置
```

### 2.4 学术史回顾段

适用场景：整理既有研究，指出已有研究的贡献和不足。

基本顺序：

```text
概括已有研究
↓
承认其合理处
↓
指出不足
↓
说明本文切入点
↓
提出新的分析方向
```

通用示例：

```text
当前学术界的研究已经从多个方面讨论了某一问题。
这些研究有助于说明研究对象的基本面貌，也为后续讨论提供了文献基础。
但是，既有研究较多集中于……，对……的思想史意义说明仍不充分。
因此\所以，需要将\把这一问题放回……脉络中考察，重点分析……如何在相关历史条件下形成。
这有助于进一步说明研究对象的理论位置。
```

### 2.5 争论辨析段

适用场景：处理不同学术观点、历史评价或理论立场之间的差异。

基本顺序：

```text
说明争论是什么
↓
指出各方观点
↓
分析争论背后的判断标准
↓
给出本文评价
↓
回到研究问题
```

通用示例：

```text
围绕某一问题的争论实质上涉及对研究对象性质的不同判断。
一种观点强调……，另一种观点则更重视……。
实际上，这两种争论是……
这两种看法的分歧并不只是结论不同，还在于它们分别采用了不同的判断尺度。
如果把研究对象放回具体历史语境中考察，就可以看到……
因此，对这一问题的评价应当同时考虑其历史条件和理论作用。
```

### 2.6 转折过渡段

适用场景：从一节转入另一节，从背景转入问题，从传播转入接受，从概念转入文本。

基本顺序：

```text
回顾前文已解决的问题
↓
指出尚未解决的问题
↓
说明下一步讨论的必要性
↓
自然转入后文
```

通用示例：

```text
前文已经说明某一问题在特定历史条件下得以形成。
但是，问题的形成并不等于问题已经获得充分解决。
要进一步理解研究对象的思想史意义，还需要考察它如何进入具体文本、具体论争或具体实践。
这一点构成后文分析的起点。
```

## 三、首句写作规则

### 3.1 首句必须承担判断功能

每段首句不能只是背景介绍，也不能只是铺垫，必须提出本段核心判断。首句应直接告诉读者本段要证明什么，避免写成铺垫句、半句或悬置句。

不建议：

```text
在某一历史时期，相关思想发生了许多变化。
```

建议：

```text
某一历史时期的思想变化集中体现为某一理论问题的重新提出。
30年代中国知识分子语境中的“新哲学”特指以唯物辩证法\辩证唯物论为核心的马克思主义哲学。
```

不建议：

```text
关于某一问题，学界已有不少研究。
```

建议：

```text
既有研究对某一问题的讨论已经形成基础性认识，但对其思想史位置的说明仍需补充。
```

### 3.2 首句中间尽量不要使用逗号

错误示例：

```text
某一概念在特定历史语境中，主要指向某一理论问题。
```

正确示例：

```text
特定历史语境中的某一概念主要指向某一理论问题。
```

错误示例：

```text
某一文本的出现，是某一思想变化的重要标志。
```

正确示例：

```text
某一文本的出现是某一思想变化的重要标志。
```

### 3.3 首句不要写成悬置句

不建议：

```text
要理解某一问题，就必须回到某一历史时期。
```

建议：

```text
某一问题的形成必须放回某一历史时期加以理解。
```
## 四、论证方法

### 4.1 历史主义方法

论证问题时强调把对象放回具体历史条件中理解。不要脱离历史条件的抽象评价，也不要只做经验描述而缺乏理论提升。

通用要求：

1. 概念要放回历史语境中理解。
2. 人物要放回其时代条件中理解。
3. 文本要放回具体论争和问题背景中理解。
4. 评价要考虑当时的理论条件和实践条件。
5. 总结要从具体历史材料中提炼，而不是从外部套入。

通用示例：

```text
评价某一思想家的理论贡献，不能只看其结论与后来的理论体系是否一致。
更重要的是，应考察他在当时的历史条件下提出了什么问题，回应了什么争论，又为后来的理论发展提供了什么思想资源。
```

### 4.2 历史与逻辑相统一

把历史展开和理论推论结合起来。不是先列事实再总结，也不是脱离事实进行概念推演，而是在历史过程中推出理论判断。

通用结构：

```text
历史事实说明问题如何发生。
理论分析说明问题为何具有意义。
二者结合起来，才能说明研究对象的思想史位置。
```

通用示例：

```text
某一文本的出现可以从历史条件中得到解释。
但是，仅仅说明文本何以出现还不够，还必须说明它在理论上改变了什么。
只有把历史发生过程和理论意义结合起来，才能准确评价该文本的思想史地位。
```

### 4.3 通过区分建立判断尺度

通过区分不同视角、不同层次、不同概念来建立判断尺度。

常见区分方式：

```text
事实问题与学理问题
传播问题与理论创造问题
通俗表达与大众掌握问题
经验描述与理论分析问题
世界视野与中国视野
历史条件与理论形态
一般性与特殊性
可能性与必要性
```

通用示例：

```text
要判断某一思想活动的意义，首先需要区分两个问题。
一个问题是它是否扩大了某一理论的传播范围。
另一个问题是它是否改变了这一理论在特定历史语境中的表达方式和理解方式。
只有区分这两个问题，才能避免把传播效果直接等同于思想史贡献。
```

### 4.4 用代表性材料支撑结论

选择代表性人物、代表性文本和代表性论争作为材料。不追求材料铺得越多越好，而是要求材料能够说明核心判断。

通用结构：

```text
选择代表性材料
↓
说明材料为什么具有代表性
↓
分析材料中的关键表述
↓
回到本段判断
```

通用示例：

```text
某一文本之所以可以作为代表性材料，是因为它集中呈现了当时相关问题的基本思路。
文本中关于……的表述，不只是一般性的观点陈述，而是反映了作者对……问题的理解。
因此，这一文本可以用来说明某一理论变化的基本方向。
```

## 五、材料处理方法

### 5.1 材料不是事实陈列

处理材料的基本原则是：材料必须支撑判断，不能只是装饰正文。

不建议：

```text
某某写了……。某某还写了……。某某又写了……。
```

建议：

```text
这些材料共同说明，某一问题在这一时期已经不只是个别人物的理论兴趣，而是成为特定思想领域中需要回答的共同问题。
```

### 5.2 材料前要有判断

引文或事实材料出现前，应先说明它要证明什么。

可用表达：

```text
这一判断可以从某一材料中得到印证。
某一文本为理解这一问题提供了线索。
这一变化在某一论述中有较清楚的体现。
```

### 5.3 材料后要有分析

材料出现后，应说明它的意义。

可用问题：

1. 这条材料说明了什么？
2. 它是否印证了前面的判断？
3. 它是否限定了概念的使用范围？
4. 它是否把问题推进到下一层？
5. 它与其他材料之间是什么关系？

通用示例：

```text
这段话的意义不在于重复某一已有观点，而在于把某一理论问题同具体历史条件联系起来。
```

### 5.4 材料要回到思想史位置

何萍常把材料最终放回思想史过程。材料分析不能只停留在“这说明作者怎么想”，还应说明“这在思想发展中意味着什么”。

通用示例：

```text
由此看，某一文本的意义并不只在于表达了作者个人观点。
更重要的是，它反映了某一理论问题在这一时期已经进入系统阐释阶段。
```

## 六、语言风格

### 6.1 长句承担关系说明

用长句说明复杂关系，但长句通常承担明确功能：界定、区分、因果说明、历史定位。

学习时应注意：

1. 长句不能只堆并列成分。
2. 长句必须有清楚主干。
3. 长句内部应有明确的逻辑关系。
4. 若逗号过多，应拆分为两个句子。

### 6.2 概念使用稳定

写作中常保持核心概念前后一致。一个概念一旦界定，后文会围绕这一界定展开。

使用规则：

1. 关键概念首次出现时应界定。
2. 后文使用概念时不要随意替换。
3. 相近概念之间应区分。
4. 不用新造概念制造理论感。

## 七、引出问题的方法模板

### 7.1 从事实到学理

```text
某一事实已经存在。
但是，事实存在并不等于学理已经成立。
要说明这一事实的理论意义，还必须回答……
```

### 7.2 从误解到重评

```text
既有评价在某一方面有合理性。
但是，这一评价也容易造成某种片面理解。
因此，有必要从……角度重新评价这一问题。
```

### 7.3 从简单化到复杂化

```text
通常的理解把某一问题归结为……
这种理解能够说明……，但不足以说明……
如果把这一问题放回……中考察，就可以看到……
```

### 7.4 从前文到后文

```text
前文已经说明……
但是，这还没有回答……
因此，后文需要进一步考察……
```

## 八、总结方法

### 8.1 总结不是重复

总结通常不是把前文重复一遍，而是指出前文分析带来了什么认识结果。

不建议：

```text
综上所述，某一问题具有重要意义。
```

建议：

```text
上述分析表明，某一问题的意义主要体现在它改变了我们对……的理解。
```

### 8.2 总结要提升层次

总结应从事实层面上升到理论层面。

通用结构：

```text
前文材料说明……
由此可以看出……
这一判断有助于重新理解……
```

通用示例：

```text
前文材料说明，某一文本并不是孤立出现的思想表达。
由此可以看出，它是特定历史条件下某一理论问题逐渐形成的结果。
这一判断有助于重新理解该文本在相关思想史中的位置。
```

### 8.3 总结可以引出新问题

总结不一定意味着结束，也可以提出下一层问题。

通用示例：

```text
这一判断说明了某一问题的形成过程。
但是，问题如何在具体文本中展开，仍需要进一步分析。
这就构成下一节讨论的起点。
```

## 九、引文处理规则

### 49.1 引文前要有判断

引文前应说明引用的目的，不能让引文突然出现。

可用表达：

```text
这一判断可以从某一文本中得到印证。
某一论者的表述为理解这一问题提供了线索。
这一变化在某一材料中有清楚体现。
为了说明这一点，有必要回到某一文本的具体表述。
```

### 9.2 引文后要有分析

引文后分析可以回答以下问题：

1. 这条引文印证了前文哪个判断？
2. 这条引文限定了哪个概念的含义？
3. 这条引文使问题获得了什么进一步说明？
4. 这条引文与前后材料之间有什么关系？
5. 这条引文能否支持段尾的结论？

可用表达：

```text
这段论述表明……
这句话的关键在于……
这一表述说明……
这一判断把……与……联系起来。
由此可以看出……
```

避免使用：

```text
这一材料处在某某问题位置上。
该材料的功能是……
这一引文完成了理论归结。
```

## 十、语句与标点规则

### 10.1 控制逗号密度

逗号过密会导致句子主干不清。修改时应优先检查逗号，而不是单纯减少句号。

问题句：

```text
某一思想在某一时期的形成，受到多种条件影响，其中既包括历史环境的变化，也包括理论资源的引入，还包括主体自身问题意识的变化，因此这一思想不能被理解为单一因素作用的结果。
```

可改为：

```text
某一思想在某一时期的形成受到多种条件影响。历史环境的变化、理论资源的引入和主体问题意识的变化，共同推动了这一思想的形成。因此，这一思想不能被理解为单一因素作用的结果。
```

### 10.2 保持句子主干清楚

每句话应尽量有明确主语、谓语和宾语。不要让修饰成分压过句子主干。

不建议：

```text
在某一历史时期中，由于多种思想资源的不断传入和不同理论立场之间的反复争论，使得某一问题逐渐成为学界关注的重点。
```

建议：

```text
某一历史时期的多种思想资源传入和不同理论立场争论，使某一问题逐渐成为学界关注的重点。
```

### 10.3 长句可以保留但必须有层次

长句适合处理复杂关系。长句不能只是多个短判断的堆叠。

可用长句：

```text
某一概念之所以能够在特定历史时期获得新的理论含义，是因为它不再只是延续既有思想传统中的一般用法，而是在新的历史问题中承担了解释现实、组织经验和回应争论的作用。
```

## 十一、判断表达规则

### 11.1 常用判断表达

可以常用：

```text
表明、说明、意味着、体现、显示、揭示、指向、有助于说明、可以看出、由此看、从这一意义上说、在一定意义上、主要表现为、集中体现为、应当理解为、需要放在……中理解
```

### 11.2 可用但要控制频率

```text
这就提出了一个问题、据此可以说、由此可见、这也就是说、不可否认、关键在于、问题在于
```

### 11.3 慎用判断表达

```text
必然、始终、完全、根本、彻底、唯一、决定性、无疑、只能、绝不是、毋庸置疑
```

原则：

1. 强判断必须有充分材料支撑。
2. 不能先下大判断再找材料补充。
3. 判断应尽量建立在解释和引文之后。

---

## 十二、学科语言规则

### 12.1 优先使用学科内表达

推荐表达：

```text
理论前提、思想条件、历史条件、理论立场、现实指向、思想脉络、理论形态、哲学观念、理论资源、中国化过程、大众化过程、世界观、方法论、理论体系、思想史意义、学术史脉络、历史语境、理论问题、思想资源
```

### 12.2 谨慎使用非本学科词语

谨慎使用或尽量不用：

```text
机制、模型、路径依赖、知识生产、赋能、嵌入、重塑、生成逻辑、话语装置、圈层、场景、接口、生态、闭环、抓手
```

原则：

1. 如果原文材料或学科语境确有需要，可以使用个别词语。
2. 如果没有必要，应使用更朴素、更准确的学科表达。
3. 不得为了增强理论感而自造概念。
4. 不得把其他领域的概念当作马克思主义哲学史论文中的解释框架。

## 十三、引号与脚注规则

### 13.1 中文引号

中文论文中的直接引文必须使用中文双引号“”，不得使用英文双引号""。

错误：

```text
某一文本指出，"……"。
```

正确：

```text
某一文本指出，“……”。
```

### 13.2 书名号

著作、文章、期刊、文件名使用书名号《》。

示例：

```text
《某一著作》
《某一文章》
《某一期刊》
```

### 13.3 脚注占位

正文中只保留脚注标号，不保留行内括注。

不建议：

```text
某一论者指出，“……”〔作者；书名；p.xx〕。
```

建议：

```text
某一论者指出，“……”。①
```

脚注占位：

```text
① 作者：《篇名或书名》，第xx页。
```

如果原始材料有内部编号，可暂时保留：

```text
① Q编号：作者：《篇名或书名》，第xx页。
```

## 十四、通用写作检查清单

### 14.1 段落检查

- [ ] 每段是否只承担一个主要论证任务。
- [ ] 每段首句是否直接提出核心判断。
- [ ] 每段首句中间是否有不必要的逗号。
- [ ] 首句之后是否对判断作出解释。
- [ ] 段尾是否回扣本段判断或自然引出下一段。

### 14.2 引文检查

- [ ] 引文前是否有铺垫。
- [ ] 引文是否真正印证前面的观点。
- [ ] 引文后是否有进一步分析。
- [ ] 是否存在引文堆砌。
- [ ] 直接引文是否被擅自改写。
- [ ] 直接引文是否使用中文双引号“”。

### 14.3 语言检查

- [ ] 是否存在逗号密度过大的句子。
- [ ] 句子主干是否清楚。
- [ ] 是否存在空泛指代。
- [ ] 是否存在机械连接词。
- [ ] 是否使用“不仅……而且……”“不是……而是……”等套式表达。
- [ ] 是否有AI式总结句。

### 14.4 判断检查

- [ ] 是否使用绝对化表述。
- [ ] 判断是否有材料支撑。
- [ ] 是否为了增强气势而过度概括。
- [ ] 是否保留了论点力度但避免下绝对结论。

### 14.5 学科语言检查

- [ ] 是否使用中文马克思主义哲学史、马克思主义哲学中国化、思想史研究中的通行表达。
- [ ] 是否使用非本学科词语。
- [ ] 是否出现自造词。
- [ ] 是否出现管理学化、传播学化、技术化、互联网化表达。

### 14.6 注释格式检查

- [ ] 正文中是否只保留脚注标号。
- [ ] 是否删除了行内括注。
- [ ] 脚注占位是否完整。
- [ ] Q编号是否只作为草稿核验信息保留。
- [ ] 切片标记是否已从正式脚注中删除。

### 14.7 问题意识检查

- [ ] 是否说明研究对象为什么成为问题。
- [ ] 是否把事实问题提升为学理问题。
- [ ] 是否指出既有理解的不足。
- [ ] 是否明确本文要回答的问题。
- [ ] 是否避免直接从材料介绍开始。

### 14.8 论证方法检查

- [ ] 是否把对象放回具体历史条件中理解。
- [ ] 是否建立了判断尺度。
- [ ] 是否区分了相近概念或相近问题。
- [ ] 是否通过代表性材料支撑判断。
- [ ] 是否避免脱离历史条件作抽象评论。

### 14.9 材料处理检查

- [ ] 材料前是否有判断。
- [ ] 材料后是否有分析。
- [ ] 多条材料之间是否有关系。
- [ ] 材料是否回到本段论点。
- [ ] 材料是否最终服务于思想史定位或理论评价。

### 14.10 语言风格检查

- [ ] 判断是否明确。
- [ ] 判断是否有铺垫。
- [ ] 是否避免情绪化批评。
- [ ] 长句主干是否清楚。
- [ ] 核心概念是否前后一致。

### 14.11 总结检查

- [ ] 结尾是否避免空泛总结。
- [ ] 结尾是否提升了前文分析。
- [ ] 结尾是否说明获得了什么新认识。
- [ ] 结尾是否自然引出下一层问题。
- [ ] 是否避免只说“具有重要意义”。

## 十五、与单项修改清单的配合方式

本指南规定写作标准。`REVISION_WORKFLOW.md` 规定修改步骤。

当需要修改论文段落时，不建议一次性要求大语言模型完成所有任务。更稳妥的做法是进入“单项修订模式”，每次只处理一个问题。

核心段落推荐顺序：

```text
单项一：段落任务是否集中
单项二：每段首句
单项三：观点解释
单项五：引文前铺垫
单项六：引文后分析
单项七：材料是否堆砌
单项八：逗号密度
单项九：句子主干
单项十：机械连接和套式表达
单项十一：判断强度
单项十二：学科语言
单项十三：中文引号
单项十四：脚注格式
单项十五：引文原文
单项十六：最终可用性
```

普通段落可以简化为：

```text
单项二：每段首句
单项六：引文后分析
单项八：逗号密度
单项十一：判断强度
单项十三：中文引号
单项十四：脚注格式
```

## 十六、风格总括

本指南追求的写作状态是：观点明确，解释充分，引文有用，分析自然，判断稳健，语言属于中文马克思主义哲学史和思想史研究的学科表达。

一句话概括：

> 以思想史问题为起点，以核心判断统领段落，以引文印证和分析推进论证，以稳健的学科语言完成中文马克思主义哲学论文写作。
