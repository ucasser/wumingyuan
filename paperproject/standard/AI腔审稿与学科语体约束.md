# AI腔审稿与学科语体约束

> 本文件整合自 `/Users/stream/Desktop/词频分析` 中的可用规则，用于补充博士论文写作项目既有三份 standard 文件。  
> OpenCode 在写作、改写、润色和终检时必须读取本文件。  
> 本文件不替代《学术写作风格指南_通用框架版.md》《学术写作风格指南_分步提示词版.md》《论文逻辑指南.md》，只负责约束学科语体、禁用 AI 腔和提供写后审稿清单。

## 一、定位

本文件解决一个具体问题：大语言模型在博士论文写作中容易把中文马克思主义哲学史、中国现代思想史和马克思主义哲学中国化的论述写成抽象、对称、升华式的 AI 文风。

这类文风常表现为：

1. 用「并不是……而是……」「不再是……而成为……」制造表面转折。
2. 用「理论共振」「方法论训练」「理论生命力」「深层张力」等词制造理论感。
3. 把主题相近写成直接影响，把问题相通写成连续发展。
4. 用排比句、升华句代替具体材料分析。
5. 用管理学、教育学、互联网语汇包装思想史判断。

OpenCode 写作时应把本文件作为语言和风格审稿规则，而不是作为内容资料来源。

## 二、写作总原则

1. 写作目标不是宏大、流畅或富有概括性，而是平稳、准确、有材料根据。
2. 每个较大的判断都必须回到具体文本、人物、时间、论争背景、概念差异或文献脉络。
3. 优先使用有限判断，不使用未经证明的总括判断。
4. 优先说明对象、问题和作用过程，不用抽象词替代论证。
5. 关系判断必须区分直接承继、问题相通、间接转化和后设回看。
6. 结尾只总结已经论证的内容，不使用排比式升华。

## 三、正向语体规则

### 3.1 判断方式

优先写：

```text
这一说法更适合理解为……
二者在问题意识上有相通之处。
在一定意义上回应了……
还需要放回……语境中理解。
其差异在于……
目前还不能据此断定二者存在直接承继关系。
```

慎写或不用：

```text
深刻改变了……
形成理论共振……
直接奠定了……
实现了理论范式的跃迁……
具有重要的理论意义和现实意义……
```

### 3.2 关系表达

| 关系类型 | 推荐表达 | 使用条件 |
|---|---|---|
| 直接承继 | 明确回应了、直接引用了、以……为讨论对象 | 有文本引用、回应、批评或明确线索 |
| 问题相通 | 在问题意识上有相通之处、都涉及……问题 | 主题相近但缺少直接证据 |
| 间接转化 | 将……问题转入……语境、把……重新处理为…… | 能说明中间环节 |
| 后设回看 | 从后来的讨论看，……可以被理解为…… | 是研究者回看，不是当时直接影响 |
| 关系不足 | 目前还不能据此断定二者存在直接承继关系 | 证据不足时必须使用 |

### 3.3 转折表达

优先使用限定式转折：

```text
不过，这一判断还需要限定。
但需要注意的是……
更稳妥地说……
这一点不能简单理解为……
如果放回……语境中看……
```

避免使用对称式升华：

```text
并不是……而是……
不是……而是……
不再是……而成为……
从……转向……
在……中实现……升华
让……真正成为……
其意义在于……
```

### 3.4 段落推进

优先按以下顺序推进：

```text
具体问题 → 文本或史实依据 → 概念差异 → 有限判断
```

避免按以下方式推进：

```text
宏大背景 → 抽象概念 → 对称转折 → 升华结论
```

## 四、禁用和慎用表达

### 4.1 禁用句式

以下句式一旦出现在模型生成文本中，必须审稿重写：

```text
并不是……而是……
不是……而是……
并非……而是……
不再是……而成为……
不仅……而且……
不仅仅是……更是……
从……转向……
既是……也是……（连续用于抽象概念时）
在……中实现……升华
让……真正成为……
其意义在于……
```

说明：原典引文、必要辨析或用户指定保留的句子可以例外；模型自行生成的对称式升华句不得保留。

### 4.1.1 禁用句式变体

以下不一定逐字命中禁用句式，但属于同构的 AI 腔总结句。模型生成文本中一旦出现，必须改写为具体对象、材料依据和作用过程：

```text
停留于……而……
停留在……而……
不只是/并不只是……还/更/而是……
由……转化为……（用于抽象升华时）
从……进入/走向……（用于抽象升华时）
低层状态 + 转折提升 + 抽象结论
先否定浅层理解，再推出高层意义的对照式结尾
```

审稿时不得只检查固定词串，还必须检查句法结构。凡是把“术语、口号、常识、经验感受”等设为低层状态，再用“而、从而、由此、进而、转化为、成为”等词推出抽象升华结论的句子，必须重写。


### 4.2 禁用词组

```text
理论共振
方法论训练
书斋中的知识积累
底层逻辑
赋能
抓手
赛道
圈层
落地
打通最后一公里
理论生命力
开放性视野
深层张力
价值自觉
问题框架
理论维度
多元路径
```

### 4.3 慎用词

| 慎用词 | 更稳妥写法 |
|---|---|
| 奠定 | 提供了、留下了、构成了……前提 |
| 决定 | 影响了、塑造了、制约了 |
| 直接影响 | 明确回应了、在一定意义上回应了 |
| 深刻影响 | 在后续讨论中有所回响 |
| 创造 | 提出、开辟、形成 |
| 真正 | 实际上、可以说、需要结合语境判断 |
| 方法论 | 方法态度、研究方法、解释方式、论证方式 |
| 降低 | 减少、削弱、压缩、避免、限制 |
| 重塑 | 重新理解、重新评价、调整了……理解 |
| 重构 | 重新组织、重新说明、系统整理 |
| 嵌入 | 置于、纳入、放回 |
| 优化 | 改进、调整、完善 |

## 五、思想史写作专项

### 5.1 不把相关写成因果

两人讨论同一问题，不等于一方影响另一方。两个文本都涉及人生观、科学、价值、社会实践等问题，也不等于后者延续前者框架。

必须区分：

```text
直接承继：有明确引用、回应或批评。
问题相通：处理同类问题，但缺少直接证据。
后设回看：研究者从后来的角度重新理解。
```

### 5.2 不过度串联

不要把不同时期、不同传统、不同问题意识的人物强行串成一条连续线索。需要主动承认跳跃点：

```text
二者的关系不在于直接承继，而在于……
这一联系还需要通过……中间环节加以说明。
仅凭主题相近，还不能说明……
```

### 5.3 时间线优先

写作前必须核对：

1. 文本发表时间。
2. 刊物创刊时间。
3. 人物活动时期。
4. 论战发生时间。
5. 后来概念是否被提前使用。

时间线不清楚时，不得写强因果判断。

## 六、写后审稿清单

每次写完初稿、改写稿或润色稿后，OpenCode 必须做一次语言终检。

### 6.1 句式检查

检查是否出现：

```text
并不是……而是……
不是……而是……
并非……而是……
不再是……而成为……
不仅……而且……
不仅仅是……更是……
从……转向……
在……中实现……升华
其意义在于……
```

若出现，判断是否为原文引文或必要辨析。若不是，直接重写。

### 6.1.1 句式变体检查

终检时必须逐句检查是否存在以下结构：

```text
停留于……而……
停留在……而……
低层状态 + 转折提升 + 抽象结论
由此成为……
使……成为……（用于结尾升华时）
```

若出现，不解释、不保留，直接改成对象主语句，写清材料中的具体做法和具体效果。总结段落尤其要检查最后两句，禁止用升华句代替论证收束。


### 6.2 词语检查

检查是否出现第四节中的禁用词组。若出现，必须改为具体材料、具体关系或具体判断。

### 6.3 论证检查

逐段检查：

1. 是否把可能有关写成直接影响。
2. 是否把主题相近写成连续发展。
3. 是否用抽象词替代具体材料。
4. 是否有未经证明的大判断。
5. 是否有引文后缺少分析的问题。
6. 是否有结尾拔高、排比或空泛收束的问题。

### 6.4 改写规则

发现问题句时，不要解释，不要为原句辩护，直接重写。

重写时必须：

1. 增加或保留具体依据。
2. 降低判断强度。
3. 明确关系类型。
4. 删除 AI 式升华。
5. 不用同义套话替换原套话。

## 七、合格与不合格示例

### 7.1 不合格写法

```text
科玄论战并不是一场简单的学术争论，而是中国现代思想在科学与人生观之间形成理论共振的重要事件。经过这场论战，哲学学习就不再是书斋中的知识积累，而成为理解社会、判断政治、参与实践的准备过程。
```

问题：

1. 使用「并不是……而是……」「不再是……而成为……」句式。
2. 使用「理论共振」「书斋中的知识积累」等空泛表达。
3. 没有说明具体文本、人物和论争关系。

### 7.2 合格改写

```text
科玄论战的核心分歧首先体现在人生观能否由科学方法加以说明这一问题上。张君劢在《人生观》中强调人生判断包含意志、情感和价值选择，丁文江则试图把科学方法扩展到人生问题的讨论之中。二者的差异不宜概括为科学与玄学的简单对立；更稳妥地说，这场论争使人生观问题在公共讨论中获得了较为明确的哲学形式。此后相关讨论若与科玄论战发生关联，还需要分别考察其文本依据和问题脉络，不能仅凭主题相近就断定存在直接承继关系。
```

特点：

1. 有人物、文本和具体问题。
2. 使用限定判断。
3. 没有二元对照升华。
4. 结论停留在已论证范围内。
