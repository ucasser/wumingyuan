# 写作入口_必读精简版

> 本文件是 DeepSeek/OpenCode 每轮写作前的最小必读入口。  
> 作用：先用短规则稳定模型行为，再按任务需要读取完整 standard 文件。  
> 本文件不替代四个 standard 文件，而是告诉 DeepSeek 如何读取、压缩和执行它们。

---

## 一、每轮先读什么

进入博士论文写作项目后，必须按顺序读取：

```text
1. /Users/stream/Documents/博士论文写作项目/AGENTS.md
2. /Users/stream/Documents/博士论文写作项目/paperproject/AGENTS.md
3. /Users/stream/Documents/博士论文写作项目/paperproject/standard/01_写作入口_必读精简版.md
```

随后按任务读取四个 standard 文件：

```text
学术写作风格指南_通用框架版.md
学术写作风格指南_分步提示词版.md
论文逻辑指南.md
AI腔审稿与学科语体约束.md
```

DeepSeek 不应把四个 standard 文件当成一堆需要机械复述的材料，而应先压缩成“本轮写作执行清单”再开始工作。

## 二、本轮写作执行清单必须包含

每次写作、改写、润色前，先输出或在内部建立以下清单：

```text
1. 当前任务属于哪一步：定位、论证设计、引文检索、首句生成、段落框架、初稿、修改、终检。
2. 当前目标题是什么。
3. 当前目在章、节、目中的位置是什么。
4. 当前目暂定问题方向或经材料修正后的核心判断是什么；未经材料检索前，只能写暂定问题方向，不能写成定论。
5. 当前论证链条是什么；论证链条必须根据已核验材料修正，不能先定观点再找材料证明。
6. 当前可用引文和材料有哪些。
7. 本轮绝对不能使用哪些句式和词语。
8. 写完后如何检查 AI 腔、引文、概念和判断强度。
```

如果用户没有提供目标题、论证链条或已确认引文，不得直接生成正式正文。可以先做最小限度定位和问题确认。

每轮写作不得把题目初读时形成的判断直接当作最终观点。写作前只能先提出暂定问题方向，随后通过本地材料、相关文献和可核验引文修正判断。材料充分时可以形成较明确的核心判断；材料不足时必须降低判断强度；材料不支持时必须调整论证重心或放弃原假设。

## 三、写作硬性红线

正文写作必须遵守：

```text
1. 正文段落优先以研究对象、经典文本、理论命题、历史过程为主语。
2. 不用“本文旨在”“本文试图”“本目要证明”“本节要说明”等提示词痕迹。
3. 每段首句要承担真实功能，不能只是空泛铺垫。
4. 重要判断必须有文本、人物、时间、论争背景、概念差异或引文支撑，并且必须接受材料检索结果的修正。
5. 引文前说明引用目的，引文后必须分析。
6. 不得改写、拼接、润色直接引文后冒充原文。
7. 没有材料支撑时，必须降低判断强度。
8. 结尾只总结已论证内容，不做排比升华。
```

## 五、思想史关系判断

不得把“主题相近”写成“直接影响”。写作时先判断关系类型：

```text
直接承继：有明确引用、回应、批评或文本线索。
问题相通：处理同类问题，但缺少直接证据。
间接转化：能说明中间环节和转换方式。
后设回看：研究者从后来角度重新理解。
证据不足：明确写出不能断定直接关系。
```

没有中间链条时，不得使用“奠定”“决定”“直接影响”“深刻影响”。

## 六、写作输出流程

DeepSeek/OpenCode 不得在同一轮里同时完成所有工作。标准顺序是：

```text
1. 初步定位与问题假设：根据题目和章节目位置提出待检验的问题方向，不预设最终观点。
2. 检索并整理相关文献、胡绳文本和可用引文。
3. 根据材料修正核心判断：材料充分则形成明确判断，材料有限则降低判断强度，材料不支持则调整论证重心。
4. 设计目级论证逻辑。
5. 匹配并确认引文。
6. 生成段落首句。
7. 搭建段落框架。
8. 写出初稿。
9. 按 AI腔审稿与学科语体约束 做语言终检。
```

这一流程的核心要求是：不得先确定观点再寻找材料证明；必须先让材料和文献校正观点，再进入论证设计和正文写作。

用户如果要求“直接写正文”，也必须先做最小限度定位：

```text
目标题 → 所属章/节 → 暂定问题方向 → 可用材料 → 经材料修正后的判断 → 写作红线
```

## 七、写后终检

每次生成正文后，必须按以下顺序检查：

```text
1. 是否出现禁用句式和禁用词。
2. 是否有“重要意义”“深远影响”等空泛判断。
3. 是否把问题相通写成直接影响。
4. 是否有引文后不分析。
5. 是否有概念前后不一致。
6. 是否有时间线、刊物、人物活动时期错误。
7. 是否有结尾拔高或排比升华。
```

发现问题时，不解释、不辩护，直接重写问题句。
