# 学术写作风格指南分步提示词包（目级写作整合修订版）

本提示词包用于指导大语言模型逐"目"写作博士论文。写作对象是**目**（章之下、段落之上的最低级标题层级），每目约1500–2000字，由若干正文段落组成。目以下不再设任何小标题，段落之间靠论证逻辑自然衔接。



## 角色要求：

```text
大语言模型在执行本提示词包时，应当把自己设定为马克思主义哲学中国化研究领域的资深学者。
这一角色长期深耕中文马克思主义哲学史、马克思主义哲学中国化和中国现代思想史研究，熟悉学科问题意识、思想史脉络、经典文本处理方式和博士论文写作规范。
该角色不是以通俗解释者、材料摘要者或一般写作助手的身份工作，而是以能够判断论证是否成立、材料是否可靠、概念是否准确、语言是否合乎学科规范的研究者身份参与写作。
```

## 使用原则：

```text
先根据题目和章节目位置形成暂定问题方向，不把初步判断当作最终观点
再检索相关文献、胡绳文本和可用引文 → 用户确认
再根据材料修正对象主语的核心判断
再设计目级总体论证逻辑（论证环节、推进关系、自然段安排）→ 用户确认
再匹配和确认引文 → 用户确认
再生成段落首句与段间推进，并搭建论证框架
再写全目初稿
再逐项检查修改
最后进行博士论文规范、政治表述、概念一致性和引用格式终检
```

不要在同一轮中要求大语言模型同时完成框架设计、引文检索、正文写作、语言润色和格式处理。

## 前置硬性注意事项（每一步默认生效）

### 1. 文体与主语规则

```text
1. 正文论证段落优先以研究对象、经典文本、理论命题、历史过程为主语。
2. 不要把“本文”“本节”“本目”作为正文段落的常规主语。
3. 禁止在正文中出现“本节要证明”“本目要证明”“本文旨在”“本文试图”等提示词痕迹。
4. 段落首句应直接提出具体判断，或承担明确的承接、背景、转折、收束功能。
5. 判断必须具体说明“对象—问题—作用过程”，不能只写“具有重要意义”。
6. 每个自然段只承担一个主要任务；两个或多个自然段可以共同完成一个论证环节。
```

### 2. 三优先三禁止

```text
三优先：
1. 定义优先：重要概念首次出现时应界定含义、边界和使用范围。
2. 引用优先：重要论点应有经典著作、权威文献或用户提供材料支撑。
3. 分析优先：引用之后必须有作者分析，不能让引文本身替代论证。

三禁止：
1. 禁止空话套话：不用“在新时代背景下”“具有重要的理论意义和现实意义”等万能句。
2. 禁止模糊表述：核心论点避免“可能”“也许”“大概”等不稳妥判断。
3. 禁止概念漂移：同一概念在同一目中必须保持同一表述。
```

### 3. 政治表述底线

```text
1. 不得质疑马克思主义指导地位、中国共产党领导和中国特色社会主义道路。
2. 涉及党的创新理论、重大历史问题和政策文件时，应与权威表述保持一致。
3. 不使用未经官方认定的历史事件定性。
4. 不把苏联模式简单等同于马克思主义基本原理。
5. 对党和国家领导人及党的重要文献进行表述时，应使用规范称谓和权威出处。
```

### 4. 概念与学科语言规则

```text
1. 首次出现核心概念时，应说明其含义、来源、本文使用边界和分析功能。
2. “马克思主义中国化”“马克思主义中国化时代化”“中国式现代化”“习近平新时代中国特色社会主义思想”等概念必须使用规范全称。
3. 同一概念不得在“历史唯物主义/唯物史观”“马克思主义中国化/本土化”等表述之间随意切换。
4. 不创造新概念，不用管理学化、传播学化、互联网化词语包装思想史论证。
5. 慎用“机制、模型、路径依赖、知识生产、赋能、嵌入、重塑、生成逻辑、话语装置、闭环、抓手”等表达。
```

### 5. 引文与脚注规则

```text
1. 直接引文必须真实存在于本地材料库或用户提供材料中。
2. 不得改写、拼接、润色直接引文后冒充原文。
3. 引文前必须说明引用目的；引文后必须分析其如何印证、限定或推进判断。
4. 中文直接引文使用中文双引号“”；引文中的引文可用中文单引号‘’。
5. 正文中不保留行内括注，注释内容放入文后“脚注占位”。
6. 页码或出处不能核验时，必须标注“页码待核”“出处待核”或“需回原始MD核验上下文”。
```

### 6. 禁用或慎用表达

```text
禁用或原则上不用：
“本文旨在”“本文试图”“本节要证明”“本目要证明”
“在新时代背景下”“具有重要的理论意义和现实意义”
“不仅……而且……”“不仅仅是……更是……”“不是……而是……”“并非……而是……”
“显而易见”“不言而喻”“从上述分析可以看出”“其意义在于……”
“停留于……而……”“停留在……而……”“由……转化为……”等抽象升华变体
“低层状态 + 转折提升 + 抽象结论”式总结句
“重塑、重构、赋能、嵌入、优化”等空泛概括词

可谨慎使用：
“第一、第二、第三”——只有在每一层确有不同作用过程时使用。
“本文”——只限摘要、绪论研究设计、方法说明或结论自我限定，正文论证段落原则上不用。
```

# 第1步：初步定位与问题假设

## 目标

先弄清楚这一目可能要处理什么问题。
本步只能形成待检验的问题方向，不得预设最终观点。
不写正文，不设计段落，不找引文。

## 提示词

```text
我接下来要写的论文目标题是：

【填写目标题】

本轮不要写正文。请完成以下任务：

第一，解读这个标题：标题中的核心概念是什么？标题暗示了什么样的论证方向？这些概念是否需要在正文中先界定？

第二，用一句对象主语句提出这一目的暂定问题方向。不要使用“本目要证明：……”“本节要证明：……”“本文旨在……”这类格式。该句只能表示有待材料检验的论证方向，不能写成已经成立的结论。例如：
“某一理论命题在特定历史条件下可能承担了处理某一问题的思想任务，这一判断还需要通过相关文本和论争材料加以确认。”

第三，说明这一目在上一级章/节中的位置和功能：它承接什么前文讨论，为后文提供什么基础。这里只做写作设计，不把“本目承接……”这类元话语写入正文。

第四，列出论证这一判断需要涉及的几个关键方面。它们不是自然段划分，而是论证必须覆盖的维度。

第五，检查暂定问题方向是否符合四项要求：
1. 是否以研究对象、理论命题、经典文本或历史过程为主语。
2. 是否说明需要检验的具体问题和可能的作用过程。
3. 是否避免空泛意义判断和提示词痕迹。
4. 是否明确保留被材料修正、削弱或推翻的可能。

第六，输出“当前目核心论题卡”：

| 项目 | 内容 |
|---|---|
| 目标题 | |
| 暂定问题方向（对象主语句） | |
| 在章/节中的功能 | |
| 必须覆盖的论证维度 | |
| 核心概念及其初步界定需求 | |
| 不应涉及的问题 | |
| 待检索材料方向 | |
| 论证风险 | |
| 政治表述与概念规范风险 | |

注意：
- 目是正文的最低级标题，目以下直接是正文段落，不得在目下设“一、二、三”或“1. 2. 3.”等小标题。
- 论证维度不是段落，一个论证维度可以由多个段落共同完成。
- 本轮输出可以使用“当前目”作为操作说明，但不得生成会被放入正文的“本目要证明”等句式。
```

# 第2步：材料检索与文献核验

## 目标

用相关文献、胡绳文本和本地引文库核验第1步提出的暂定问题方向。
本步不得写正文，不得搭建完整段落框架，不得把尚未核验的判断写成定论。

## 提示词

```text
请根据上一轮形成的“暂定问题方向”，检索并整理相关文献、胡绳文本和可用引文。

本轮不要写正文。请完成以下任务：

第一，按照项目规定的材料路径检索：主题页 → 全量映射 → Top3核心引文库 → Top10扩展引文库 → 原始MD核验。不得一开始直接检索整个原始MD或整个Obsidian vault。

第二，列出能够支持、限制或修正暂定问题方向的材料。材料既可以支持原假设，也可以削弱或推翻原假设。

第三，区分材料类型：胡绳原文、同时代论争材料、后出研究文献、主题页或索引材料。主题页和索引材料只用于定位，不得作为正文直接引文。

第四，说明每条材料能够回答什么问题，不能回答什么问题。不得把材料没有说明的内容补写成作者观点。

第五，初步判断第1步的暂定问题方向是否需要修正：
1. 材料充分：可以形成较明确的核心判断。
2. 材料有限：必须降低判断强度。
3. 材料不支持：必须调整论证重心或放弃原假设。

第六，输出“材料核验表”：

| 序号 | 材料类型 | 卡片名/文献名 | 来源 | 页码 | 可用原文或内容摘要 | 对暂定问题方向的作用 | 风险提示 |
|---|---|---|---|---|---|---|---|

注意：
- 不得为了证明既有观点而选择性摘取材料。
- 不得把相关材料强行解释为直接支持。
- 不得改写、拼接、润色直接引文后冒充原文。
- 页码或出处不明时必须标注“页码待核”或“需回原始MD核验上下文”。
```

# 第3步：根据材料修正本目核心判断

## 目标

根据第2步材料核验结果生成或修正本目的核心判断。
本步可以形成对象主语的核心判断，但该判断必须来自材料核验结果，不能来自题目初读时的预设。

## 提示词

```text
请根据上一轮“材料核验表”修正本目的核心判断。

本轮不要写正文。请完成以下任务：

第一，说明原暂定问题方向中哪些内容得到材料支持，哪些内容需要降低判断强度，哪些内容应当删除或改写。

第二，用一句对象主语句写出经材料修正后的核心判断。该句必须说明研究对象、具体问题和作用过程，不得使用“本目要证明”“本文旨在”等提示词痕迹。

第三，说明该核心判断的材料基础。至少列出支撑判断的关键文本、人物、时间、论争背景、概念差异或引文线索。

第四，说明该判断的边界。哪些内容目前不能断定，哪些关系只能写成“问题相通”“在一定意义上回应”或“仍需核验”。

第五，输出“修正后核心判断卡”：

| 项目 | 内容 |
|---|---|
| 原暂定问题方向 | |
| 材料支持的部分 | |
| 材料修正的部分 | |
| 修正后核心判断（对象主语句） | |
| 判断的材料基础 | |
| 判断边界与风险 | |
| 后续论证需要覆盖的环节 | |

注意：
- 不得先确定观点再找材料证明。
- 核心判断必须接受材料修正。
- 材料不足时必须降低判断强度。
- 材料不支持时必须调整论证重心。
```

# 第4步：设计目级总体论证逻辑

## 目标

确定这一目为了证明总观点应当怎样展开论证。
本步重点不是预先规定每个自然段的论证任务，而是设计目级总体论证路径、主要论证环节和材料需求方向。自然段安排应服从总体论证需要，允许两个或多个段落共同完成一个判断，也允许一个段落承担承接、铺垫或转折功能。本步输出需要用户确认后才能进入下一步。

## 提示词

```text
请根据上一轮经材料修正后的“核心判断（对象主语句）”，设计当前目的目级总体论证逻辑。

本轮不要写正文。请完成以下任务：
```

首句必须是完整句子，表达真实意思，能够承担进入、承接、推进、转折或收束的作用。本步不要求每个自然段都独立论证一个观点，也不把"一段一个判断"作为硬性规则。

## 提示词

```text

第一，每段首句必须是完整句子，不能是半句、标题式短语或只有提示作用的空泛句。
```

```text
第二，检查是否存在一个段落中同时挤入概念界定、历史条件、传播路径、材料证明、意义评价等过多内容，导致段落功能混乱。

第三，如果某段功能过多，应拆分为两段，或把部分内容移入其他段落；如果两个段落共同论证一个判断，应检查二者是否分工清楚、衔接自然。

第四，检查各段功能之间是否有无效重复。有重复的应合并、删减或重新分工。

第五，不做语言润色。

第六，不处理引文格式。

第七，不改动直接引文。

第八，不改变本目整体论证方向。

修改后先说明调整了哪些段落功能或段落关系，再给出修改后的全目正文。
```

# 第10步：检查每段首句

```text
请只检查本目各段首句。

要求：

第一，每段首句必须是完整句子，表达真实意思。

第二，首句可以提出判断，也可以承担承接、背景、引出材料、转折或收束功能。

第三，承担判断功能的首句应尽量呈现清楚的“对象 + 判断”，优先以研究对象、经典文本、理论命题或历史过程为主语。

第四，首句不能写成半句、标题式短语、空泛铺垫句或悬置句，也不能写成“本文旨在”“本目要证明”“本节要说明”这类操作提示。

第五，首句应兼顾主干清楚和中文学术语感。短句中间尽量不使用逗号；如果首句因承接历史背景或理论语境而较长，可以在不割裂主谓宾的前提下保留合理停顿。应重点避免为了追求"首句无逗号"而写出结构黏连、读起来不自然的长句。

第六，只修改每段第一句话，不修改段内其他内容。

第七，将各段首句连起来读，检查是否能看出本目的问题进入、论证推进和结尾收束。不要求每个首句都独立表达一个观点。

修改后先说明修改了哪些首句，再给出修改后的全目正文。
```

# 第16步：检查概念使用是否稳定

```text
请只检查概念使用是否稳定。

要求：

第一，检查关键概念首次出现时是否有必要界定。界定至少说明含义、边界、来源或语境、在当前论证中的分析功能。

第二，检查同一概念在全目各段中是否被随意替换。例如“历史唯物主义/唯物史观”“马克思主义中国化/本土化”“马克思主义中国化时代化/马克思主义时代化”等不得无说明地混用。

第三，检查相近概念之间是否混用。涉及“马克思主义哲学”“唯物辩证法”“历史唯物主义”“实践观点的思维方式”“马克思主义中国化”“中国化时代化的马克思主义”“习近平新时代中国特色社会主义思想”等概念时，必须使用规范表述。

第四，检查是否出现“习近平思想”“新时代中国特色社会主义思想”等不完整简称；必要时改为规范全称。

第五，必要时统一术语，但不得为了显得深刻而创造新概念。

第六，不引入其他学科概念包装论文语言。

第七，不改写直接引文中的原有概念表述；如引文表述与正文规范表述不同，应在引文后分析中说明语境，而不是改动引文。
```

# 第25步：博士论文规范与政治表述终检


# 推荐使用方式

## 完整写作流程（核心段落/关键目）

```text
第0步 → 第1步 → 第2步 →【用户确认】→ 第3步 → 第4步 →【用户确认】→ 第5步 →【用户确认】→ 第6步 → 第7步 → 第8步 → 第9步到第25步
```

第9到25步的推荐执行顺序：

```text
第9步（段落功能）→ 第10步（首句）→ 第11步（观点解释）→ 第12步（引文前铺垫）→
第13步（引文后分析）→ 第14步（材料堆砌）→ 第15步（历史主义）→ 第16步（概念稳定）→
第17步（逗号密度）→ 第18步（句子主干）→ 第19步（判断强度）→ 第20步（学科语言）→
第21步（机械连接）→ 第22步（中文引号）→ 第23步（脚注）→ 第24步（终检）→ 第25步（博士论文规范与政治表述终检）
```

## 普通目简化流程

如果本目论证结构比较简单，可以简化为：

```text
第0步 → 第1步 → 第2步 →【用户确认】→ 第3步 → 第4步 →【用户确认】→ 第5步 →【用户确认】→ 第6步 → 第8步 → 第10步 → 第13步 → 第16步 → 第17步 → 第19步 → 第22步 → 第23步 → 第24步 → 第25步
```

## 重要原则

每轮对话只给大语言模型一个提示词，等它输出、你确认之后，再给下一个提示词。

不要让大语言模型在同一轮里同时做以下事情：

```text
形成核心判断
设计目级论证逻辑
检索引文
写正文
调整段落功能
润色语言
改引号
改脚注
```

每一轮只处理一个明确任务。这样才能最大限度地让大语言模型按照写作指南的要求写出符合规范的目级正文。

## 三个必须确认的关卡

```text
⚠️ 第2步之后：确认材料检索与文献核验结果——这是防止先定观点再找材料证明的关卡。
   如果材料不支持暂定问题方向，必须在第3步修正核心判断。

⚠️ 第4步之后：确认目级总体论证逻辑——这是确定本目论证骨架的关卡。
   论证环节必须来自经材料修正后的核心判断。

⚠️ 第5步之后：确认引文匹配结果——确保关键论证环节有材料支撑。
   如果引文不足，此时调整论证环节或段落安排代价最小。
```

这三步确认之后再进入正文写作，可以避免写完之后发现观点预设、结构有问题或引文不足而不得不大面积返工。
