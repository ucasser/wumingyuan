# AGENTS.md

本文件是 `paperproject` 文件夹内的局部工作规则。  
根目录的 `AGENTS.md` 是项目总规则。本文件只补充“论文写作目录”的具体规则，不得与根目录规则冲突。

开始任何任务前，必须先读取并遵守 `../AGENTS.md`，再执行本文件中的局部规则。

进入本目录进行写作、改写、润色或终检前，还必须读取以下 standard 文件：

```text
./standard/学术写作风格指南_通用框架版.md
./standard/学术写作风格指南_分步提示词版.md
./standard/论文逻辑指南.md
./standard/AI腔审稿与学科语体约束.md
./standard/01_写作入口_必读精简版.md
```

其中 `./standard/01_写作入口_必读精简版.md` 是每轮写作前的短入口，必须先读；`./standard/AI腔审稿与学科语体约束.md` 专门用于约束大语言模型默认文风。写作完成后必须依据该文件检查并重写 AI 腔、管理学腔、教育学腔、二元对照升华句和空泛结尾。

## 一、本目录用途

当前目录是论文写作输出目录：

```text
./paperproject
```

本目录用于保存论文提纲、章节草稿、段落草稿、材料清单、引文筛选表、论证结构表、修改稿和阶段性写作报告。

本目录不是原文库，不是引文库，不是 Obsidian vault。OpenCode agent 可以在本目录中新建、修改和整理写作文件，但不得把本目录当作引文来源。

## 四、论文写作时的引文检索顺序

OpenCode agent 在本目录写作时，必须遵守以下顺序：

第一，先检索主题页：

```bash
rg -n "关键词1|关键词2|关键词3" "../原文库_obsidianvault/主题页"
```

第二，如果存在相关主题页，必须先阅读主题页中的主题说明、相关概念、重点引文卡片、推荐检索词和写作用途。

第三，如果主题页没有直接命中，或者用户给出的主题较冷门、较细碎，必须检索全量映射：

```bash
rg -n "关键词1|关键词2|关键词3" "../辅助索引/全量映射"
```

第四，根据主题页或全量映射定位到的卡片，打开 Top3：

```bash
rg -n "卡片名|关键词1|关键词2" "../原文库_obsidianvault/02_核心引文库T3"
```

第五，Top3 材料不足时，才检索 Top10：

```bash
rg -n "关键词1|关键词2|关键词3" "../原文库_obsidianvault/03_扩展引文库T10"
```

第六，只有需要核验页码、原文上下文、OCR 或完整章节语境时，才查原始 MD：

```bash
rg -n "原文关键短语" "../原始md文档"
```

不得一开始直接检索整个 vault。不得一开始直接检索原始 MD。不得把辅助索引或全量映射当作论文引文来源。不得把 Top10 当作默认入口。

## 五、全量映射使用规则

`../辅助索引/全量映射` 是查表层，不是引文来源。

它的作用是：

```text
把用户问题对应到主题页
发现相近主题词
定位相关 Top3 卡片
判断某些主题是否低置信或需要人工复核
```

使用流程：

```text
全量映射定位主题页和卡片名
→ 回到 Top3 或 Top10 打开卡片
→ 阅读命中段和回填上下文
→ 判断是否可用
→ 必要时回原始 MD 核验
```

不得引用全量映射表中的说明文字作为论文引文。

## 六、宽泛主题必须转化为精确检索词

如果用户给出的主题过宽，OpenCode agent 不得直接用宽词检索并据此下结论。

例如，用户说“苏联哲学”，应先转化为“德波林、机械论派、米丁、尤金、哲学党性、哲学战线、联共中央、斯大林、教条化”。

例如，用户说“大众化”，应先转化为“新哲学大众化、艾思奇、大众哲学、胡绳、新哲学的人生观、陈唯实、哲学到大众中去、通俗宣传”。

例如，用户说“中国化”，应先转化为“马克思主义的中国化、中国化的马克思主义、实践论、矛盾论、毛泽东哲学思想、六届六中全会、中国作风、中国气派、中国特点”。

优先从主题页和全量映射中扩展检索词。

## 七、引文材料筛选规则

正式写作时优先使用主题页明确列为重点卡片的材料、全量映射中置信度较高并能定位到 Top3 的材料、Top3 中命中词具体的材料、回填上下文与论点直接相关的材料、包含明确理论判断或思想评价的材料。

谨慎使用 Top10 中的弱相关材料、全量映射中标为低置信或待建主题页的材料、只命中一个泛词的材料、只有背景叙述的材料、页码为空的材料、OCR 疑似错误的材料。

不得使用只命中“哲学”“马克思主义”“中国”“研究”等泛词的材料、卡片标题相关但正文不支持论点的材料、来源和页码无法判断且无法核验的材料、明显 OCR 错乱的材料。

## 八、写作输出格式

如果用户要求“找引文”“列材料”“查相关资料”，默认输出 Markdown 表格：

```markdown
| 序号 | 主题 | 卡片名 | 来源 | 页码 | 可用原文 | 可用理由 | 风险提示 |
|---|---|---|---|---|---|---|---|
```

如果用户要求“写段落”，默认采用中文社科论文风格：首句提出核心判断，后文解释判断，插入原文引证，进一步分析，形成小结。

如果段落有多层意思，可以使用“第一、第二、第三”。

不得使用以下套式表达：

```text
不仅……而且……
不仅仅是……更是……
不是……而是……
并非……而是……
并不是……而是……
不再是……而成为……
从……转向……
```

少用或不用以下空泛概括词：

```text
重塑
重构
转向
优化
赋能
嵌入
抓手
底层逻辑
理论共振
方法论训练
理论生命力
深层张力
```

## 九、脚注和引文格式

生成论文正文时，直接引文必须使用中文引号“”。不得使用英文双引号。

脚注占位采用 Markdown 形式：

```markdown
正文中的引文内容。[^1]

[^1]: 作者：《书名》，出版地：出版社，出版年份，第X页。
```

如果页码缺失：

```markdown
[^1]: 作者：《书名》，出版地：出版社，出版年份，页码待核。
```

不得编造页码。不得编造文献来源。不得改写原文后冒充直接引文。

## 十一、常见任务流程

### 任务一：查找某主题引文

```text
1. 检索主题页
2. 阅读相关主题页
3. 如果主题页不足，检索全量映射
4. 打开相关 Top3 卡片
5. Top3 不足时检索 Top10
6. 输出候选引文表格
7. 标注可用性和风险
```

### 任务二：写一个论文段落

```text
1. 明确段落核心判断
2. 检索主题页
3. 必要时查全量映射
4. 读取相关 Top3 卡片
5. 选择最能支撑判断的引文
6. 写出论文段落
7. 用脚注占位标注来源
```

### 任务三：核验用户已有段落

```text
1. 抽取段落中的核心判断
2. 查主题页、全量映射和 Top3
3. 判断现有引文是否能支撑判断
4. 如果不能支撑，直接指出问题
5. 给出替代引文或改写方案
```

### 任务四：扩展主题页

```text
1. 查现有主题页是否已有相关主题
2. 查全量映射和 Top3
3. 找到相关卡片
4. 新建或修改主题页
5. 主题页必须包含主题说明、相关概念、重点引文卡片、推荐检索词、写作用途
```

## 十三、核心原则

本目录的目标不是保存更多材料，而是产出更准确、更可核验、更符合论文规范的写作成果。

OpenCode agent 必须坚持：

```text
主题页优先
全量映射辅助定位
Top3 优先
Top10 备用
原始 MD 用于核验
写作成果保存在本目录
不编造
不乱搜
不大范围读取
不迎合错误方案
```
