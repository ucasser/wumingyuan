# OpenCode 全量映射版追加规则

本规则用于配合 `主题页索引层_全量映射版_基于Top3` 使用。

## 一、检索顺序

OpenCode agent 查找引文时必须遵守：

```text
主题页 → 全量映射表 → Top3 核心引文库 → Top10 扩展引文库 → 原始 MD 核验
```

## 二、全量映射表用途

`Top3_全量主题词映射表.csv` 和 `Top3_全量主题词映射表.jsonl` 用于定位，不是引文来源。

使用流程：

```text
用户问题 → 查主题页
如果主题页不够明确 → 查全量映射表
从映射表获得对应主题页、相近主题词、卡片名
再回到 Top3 打开卡片
```

## 三、不得直接引用映射表

映射表中的“相近主题词”“匹配依据”“处理建议”都是导航信息，不能当作论文正文或原文引文。

## 四、低置信条目处理

如果映射表中某条主题词的置信度为“低”或“待人工归类”，OpenCode agent 必须明确提醒用户：

```text
该条目为低置信映射，需要打开卡片和原始 MD 进一步核验。
```

## 五、省 token 规则

不得一次性读取全部映射表。应使用 `rg` 或条件搜索定位少数行，例如：

```bash
rg -n "德波林|机械论派|米丁" "./辅助索引/全量映射/Top3_全量主题词映射表.csv"
```

找到卡片名后，再打开 Top3 中对应卡片。
