# 主题页索引层_全量映射版_基于Top3

本包基于完整 `02_核心引文库T3.zip` 生成，目标是补足上一版“核心主题页索引层”没有全量覆盖 1604 个主题词的问题。

## 包含内容

```text
全量映射/
  Top3_全量主题词映射表.csv
  Top3_全量主题词映射表.jsonl
  Top3_主题词相近关系边表.csv
  Top3_全量主题词映射报告.md
  Top3_低置信与待建主题页清单.md

主题页全量映射/
  00_主题页全量映射总索引.md
  各主题页对应的全量卡片清单

OpenCode规则/
  AGENTS_全量映射版追加规则.md
```

## 应该放在哪里

建议放入你的项目根目录下的：

```text
/Users/stream/Documents/博士论文写作项目/辅助索引
```

不要放入 Smart Connections 索引范围。它是给 OpenCode agent 精确查表和定位用的，不适合向量化。

## 使用方法

第一，OpenCode agent 仍然先查：

```text
./原文库_obsidianvault/主题页
```

第二，主题页不够明确时，再查：

```text
./辅助索引/全量映射/Top3_全量主题词映射表.csv
```

第三，根据映射表里的卡片名，回到：

```text
./原文库_obsidianvault/02_核心引文库T3
```

打开原卡片。

## 重要说明

本版做到了“每个 Top3 主题词都有一条映射记录”。但这仍然是机器辅助归类，不是人工逐条终审。低置信和待人工归类条目已经单独列出，写作时必须核验。
